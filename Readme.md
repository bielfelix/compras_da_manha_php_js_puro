# Morning Shopping List

An older shopping-list application built with plain PHP, JavaScript, AJAX and MySQL.

This version predates the CodeIgniter rewrite and is kept as historical evidence of my work with framework-free PHP applications.

## What the project contains

- Plain PHP application structure
- MySQL database script
- AJAX endpoints
- JavaScript interactions
- CSS and image assets
- CRUD-oriented shopping-list flows

## Historical context

The main value of this repository is showing the earlier implementation before I rebuilt the same idea using CodeIgniter.

The later framework-based version is available at:

https://github.com/bielfelix/compras_da_manha_php_codeigniter

This repository is legacy code and does not represent my current preferred project structure.
